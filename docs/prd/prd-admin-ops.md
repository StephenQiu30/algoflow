# 产品需求文档：统一运营与知识库切片管理后台 (Admin & Ops PRD)

> **文档编号**：PRD-ADM-001  
> **所属模块**：03. PRD  
> **路由入口**：`frontend/src/app/admin/` (严格禁止独立前端工程)  
> **权限控制**：基于 Sa-Token 角色守卫 (`UserRoleEnum.ADMIN`)

---

## 1. 业务目标与规范原则

运营管理后台用于维护系统的核心知识库切片、大模型 Prompt 模板、社区内容审查及全站审计监控。根据项目总则要求，**Admin 模块全量内嵌在前端 App Router 中（`/admin/*`）统一维护，严禁分立独立前端工程**。

---

## 2. 核心功能规范

### 2.1 知识库与切片管理 (`/admin/knowledge`)
* **知识库列表维护**：创建/编辑知识库（如“官方排序算法库”、“面试真题算法库”）；
* **文档自动分块与向量化管道**：
  - 上传 Markdown 文档后，后台触发 Flexmark 语法树 AST 深度分块；
  - 列表展示分块明细（切片 ID、章节标题、Token 长度、向量同步状态）；
  - 支持管理员手动修改切片文本或重新执行向量化同步（Elasticsearch Sync）。

### 2.2 召回评测实验室 (`/admin/evaluation`)
* **多路召回效果评测**：输入测试 Query（如“快速排序为什么会退化到 $O(n^2)$？”），同时比对纯文本 BM25 检索结果与向量 Cosine 检索结果；
* **相似度分数与重排测试**：直观展示每个切片的 Hit Score，辅助调优分词分词器与分块滑窗大小。

### 2.3 用户与权限管理 (`/admin/users`)
* **用户档案与状态控制**：查看注册用户列表、角色变更（普通用户、教研员、超级管理员）、账号临时封禁与解封；
* **会话强退**：支持管理员一键踢出违规或异常在线会话（Sa-Token Session 踢人）。

### 2.4 系统审计与安全监控 (`/admin/audit`)
* **API 请求与访问日志**：可视化展示高频接口请求耗时（P95/P99）、IP 归属地分布；
* **异常堆栈追踪**：捕获全站业务与系统级未捕获异常，快速定位排障；
* **邮件与通知推送记录**：监控异步邮件与站内信投递成功率。
