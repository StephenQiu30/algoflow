# 产品需求文档：社区讨论、题解博客与学习成长 (Community PRD)

> **文档编号**：PRD-COMM-001  
> **所属模块**：03. PRD  
> **路由入口**：`frontend/src/app/blog/` / `frontend/src/app/user/`  
> **后端契约**：`algorithm-api-post` / `algorithm-api-user`

---

## 1. 业务目标

将单向的工具型演示升维为活跃的**算法学习与知识共创社区**。学习者不仅在此观摩演练，还能记录个人打卡足迹、发表题解心得、研读深度技术博客，形成从“学习”到“输出”的完整正向闭环。

---

## 2. 功能模块划分

### 2.1 算法题解与技术博客系统 (`/blog`)
* **题解流与多维筛选**：支持按算法类别（如“快速排序”、“归并排序”）、排序难度（简单/中等/困难）、最新发布、最多点赞进行多维筛选；
* **Markdown 沉浸式阅读器**：支持标准 GitHub Flavored Markdown 渲染、语法高亮代码块、一键复制代码、目录大纲（TOC）滚动监听与平滑跳转；
* **在线文章编辑器**：
  - 支持 Split View（左侧编辑，右侧实时双向同步预览）；
  - 支持上传题解封面与插图（通过 `algorithm-file-service` 直传对象存储）；
  - 自动暂存草稿至浏览器 LocalStorage，防止误关闭丢失数据。

### 2.2 社区互动体系
* **轻量点赞与收藏**：基于 Redis 集合与 Redisson 实现高并发无感点赞与收藏；
* **二级嵌套评论区**：支持针对题解的评论、回复与 @互动，支持表情与快捷代码片段。

### 2.3 用户中心与学习成长 (`/user`)
* **学习足迹看板**：记录用户已掌握的排序算法数量（如 14/19 种）、累计演练步数、累计 AI 提问次数；
* **成长里程碑勋章**：
  - *“秩序启蒙”*：完成前 3 种基础排序演练；
  - *“分治大师”*：深入完成归并与快速排序的所有极端数据集测试；
  - *“心流学者”*：与 RAG 导师互动问答达 20 次；
* **个人设置与资料维护**：支持更新昵称、个性签名、更换头像与修改登录密码。
