## 1. 产品背景与定位

学习者在观察排序推演时，经常对特定步骤的交换原因产生困惑。AI 导师定位为**深度绑定演练工作台上下文、依托权威教研知识库检索的专业算法助教**，杜绝脱离实际代码的泛泛而谈。

---

## 2. 范围与边界 (Scope & Boundaries)

### 2.1 包含功能 (In Scope)
* **演练上下文感知**：提问自动携带算法名、当前步骤、当前指针及高亮伪代码行；
* **快捷启发式提问 (Quick Chips)**：根据算法阶段动态推荐预置问题；
* **流式打字机答疑 (SSE)**：打字机动效呈现 Markdown、LaTeX 公式与代码高亮；
* **权威切片溯源**：答案末尾附带 1~3 张知识库来源卡片，点击打开原文浮层预览；
* **主动中断 (Abort)**：支持用户随时中断推理。

### 2.2 明确排除 (Out of Scope)
* 排除与算法无关的日常闲聊对话；
* 不开放用户直接修改知识库向量嵌入参数的权限（管理员专有）。

## 4. 功能详细规格与交互规则

### 4.1 上下文捕获与提问组装
前端点击提问时，从 `Zustand` 状态机提取快照：
```json
{
  "algorithmType": "quickSort",
  "stepIndex": 12,
  "arraySnapshot": [15, 32, 42, 88, 9, 64],
  "comparing": [0, 2],
  "swapping": [],
  "highlightLine": 12,
  "codeLineText": "if (arr[i] < pivot) i++;"
}
```
顶部渲染动态指示胶囊，支持点击一键切换“开启/关闭当前上下文”。

### 4.2 知识库溯源卡片联动
* 后端推送 `event: source` 时，前端解析来源文件与段落锚点；
* 鼠标悬浮展示切片核心摘要；
* 点击触发右侧/居中文档浮层预览，直接对应 `docs/algorithms/` 专章。

---

## 5. 非功能性需求 (NFR)

* **首字延迟 (TTFB)**：流式响应首字 ≤ 1200ms；
* **公式渲染**：KaTeX 解析零报错；
* **网络韧性**：连接断开自动重试 1 次，支持携带 `Last-Event-ID`。

---

## 6. 验收标准与交付清单

- [ ] 提问请求体包含完整演练上下文快照；
- [ ] 回复内容准确解释当前步骤的指针决策；
- [ ] 溯源卡片准确指向官方算法 Markdown 章节；
- [ ] 点击“停止生成”即刻切断 SSE 请求。
