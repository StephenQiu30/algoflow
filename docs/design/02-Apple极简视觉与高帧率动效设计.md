# Apple 极简视觉与高帧率动效设计

> **文档编号**：DES-02  
> **状态**：已确认。依据：[需求01 §4 NFR-01 & NFR-04](../requirement/01-产品总览与系统需求规格说明.md)，设计规范基线 [frontend/DESIGN.md](../../frontend/DESIGN.md)；已确认、建议与待定分别标注。不要复制 BACKLOG 的进度表。

---

## 1. 摘要

针对算法教学场景中“视觉干扰过多、长时间观看眼部疲劳、位移动画卡顿丢帧”的问题，本设计确立基于 Apple 极简设计哲学的全站设计系统：内容为先、克制单一交互色（Action Blue `#0066cc`）、高帧率 GSAP 60 FPS 物理插值动效以及 WCAG 2.1 AA 级无障碍规范。

---

## 2. 参与者与职责

* **设计与交互确认**：UI/UX 负责人、前端主程；
* **技术评审**：前端动效工程师；
* **实施责任**：`frontend` 前端团队。

---

## 3. 背景与约束

* **系统现状**：演练工作台基于 Next.js 15 + Tailwind CSS + GSAP 构建；
* **约束红线**：全站禁止非功能性花哨渐变与厚重阴影，UI 容器与卡片退居背景，舞台留给算法数据本身；
* **硬件性能基线**：算法矩阵必须在 60 FPS 下稳定演算，且必须支持系统级 `prefers-reduced-motion`。

---

## 4. 目标与非目标

### 4.1 核心目标
1. 建立统一的色彩 Token、SF Pro 现代排版网格与发丝线（Hairline）材质；
2. 规范算法演练状态与颜色映射，满足色弱人群无障碍对比要求；
3. 基于 GSAP 实现流畅位移，速度调节达 4.0x 时自适应简化辅助动效，杜绝丢帧。

### 4.2 非目标
* 不在演练画布上堆叠炫光粒子特效，保持教学严肃性。

---

## 5. 使用场景与链路

用户进入 `/sorting/[algo]` 工作台：
1. 页面载入：极简发丝线卡片无缝呈现，默认 Action Blue 交互焦点；
2. 演练开始：比较中的元素由静止状态自然过渡为琥珀黄 (`#f5a623`)，交换元素触发物理缓动平滑换位；
3. 演练完毕：全量柱体以翡翠绿 (`#34c759`) 渐变闪烁完成庆祝。

---

## 6. 核心价值

* **专注力沉浸**：消除 UI 噪音，帮助学习者构建纯粹的算法数据心流；
* **极致流畅**：GSAP 补间动画硬件加速，高频推演不引起页面卡死。

---

## 7. 方案详述

### 7.1 色彩系统 Token 规约 [已确认]

| Token 名称 | Light 模式 | Dark 模式 | 语义与视觉定位 |
| :--- | :--- | :--- | :--- |
| **`primary`** | `#0066cc` | `#2997ff` | **唯一主交互色**：主按钮、当前活动指示 |
| **`primary-focus`** | `#0071e3` | `#0077ed` | 键盘操作 Focus 焦点高亮环 |
| **`ink` (正文)** | `#1d1d1f` | `#f5f5f7` | 一级标题、代码正文字色 |
| **`hairline`** | `#e0e0e0` | `#2d2d2d` | 极细卡片与分割线描边 (1px)，替代阴影 |
| **`state-comparing`** | `#f5a623` | `#ffb340` | 算法状态：两元素正在进行大小比对 |
| **`state-swapping`** | `#d0021b` | `#ff453a` | 算法状态：两元素正在执行内存交换 |
| **`state-sorted`** | `#34c759` | `#30d158` | 算法状态：元素已处于最终有序位置 |
| **`state-pivot`** | `#af52de` | `#bf5af2` | 算法状态：基准值元素 (Pivot) |

### 7.2 GSAP 物理动效参数标准 [已确认]
* **换位缓动**：`power2.out`，位移自然递减；
* **色彩状态变换**：`duration: 0.15s, ease: "power1.inOut"`；
* **极速自适应 (4.0x)**：当播放速率 `≥ 2.0x` 时，自动跳过抛物线插值，直接采用轻量级水平位移，确保帧率稳定在 60 FPS。

### 7.3 用户故事映射 [已确认]
* 支撑用户故事 [US-101 算法单步与多速演示控制](../requirement/02-敏捷用户故事与验收准则.md#故事-101-算法单步与多速演示控制)；
* 支撑用户故事 [US-103 指针与动态比较高亮](../requirement/02-敏捷用户故事与验收准则.md)。
