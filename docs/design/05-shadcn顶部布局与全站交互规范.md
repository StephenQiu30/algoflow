# shadcn 顶部布局与全站交互规范

> DES-05 · 更新：2026-10-23。视觉唯一来源：[主设计规范](../DESIGN.md)；当前设计入口与验证边界：[DES-06](06-Figma全站设计交付与验收.md)。本文原位维护，不记录迭代流水账。

## 共享 Layout 与导航

所有页面位于 frontend，管理页面位于 frontend/src/app/admin，禁止独立 Admin 工程。

```text
BasicLayout
  SiteHeader: Logo A + 全站导航 / 弹性空白 / 搜索 + 通知 + 主题 + 头像
  main: 标题与上下文 / 内容 / 操作与状态
```

桌面保留发现、算法学习、可视化演练、学习社区四项；个人与管理不替换全站导航。小于 1024px 将四项全站导航折叠为 Sheet；个人、管理和设置均不增加第二行菜单或分区选择器。个人中心和运营管理从头像菜单进入，管理权限展示仍由角色控制。当前导航同时提供可见选中状态与 aria-current。跨模块进入，以及明确的「返回个人中心 / 返回运营管理 / 返回账户设置」，均从目标页顶部开始；详情返回列表保留查询、页码和阅读位置，无有效历史时回所属列表；未保存内容先走草稿保护。

### 账户菜单

| 分组 | 条目 | 目标或行为 |
| --- | --- | --- |
| 身份 | 名称、账号与示例角色 | 非导航的 DropdownMenuLabel |
| 个人 | 个人中心 | 个人空间概览 |
| 个人 | 公开主页 | 对外资料与动态 |
| 个人 | 通知中心 | 通知列表 |
| 个人 | 账户设置 | 个人资料设置 |
| 管理 | 运营管理 | 管理概览；仅具备管理权限时渲染 |
| 会话 | 退出登录 | 原型清除演示管理角色并进入同尺寸登录页；生产实施时结束真实会话 |

普通用户与管理员分别有共享组件。当前区域用浅底和 Lucide Check 标识，深色模式保留 Check；主题继续使用顶栏独立入口，不重复加入头像菜单。

菜单宽 264px、内边距 8px、分组间距 8px、圆角 12px；条目高 44px、文字 14px、图标 18px、当前标记 16px。菜单右边缘对齐头像，向下偏移 8px，手机保持在视口内。复用 popover、popover-foreground、accent 及既有轻阴影，不加描边或全屏暗色遮罩。视口、顶栏、页边距、字号基线不变。

实现组合：DropdownMenu → Trigger（Button + Avatar/Fallback）→ Content → Label / Group / Item。导航项使用 Radix asChild 与 Next Link；触发器名称为“打开账户菜单”。焦点、键盘与关闭返回沿用 Radix。管理入口显示条件与服务端授权分别执行，隐藏入口不能代替鉴权。

每个菜单项只绑定一次点击动作；退出登录可在同一动作序列中清理演示角色再跳转登录页。组件主件不得携带首页占位导航，以免实例同时触发两个页面。选择条目后关闭菜单；再次点击头像、外部点击和 Esc 关闭而不导航。原型角色变量仅用于评审，普通用户无管理入口，直接进入管理页显示无权限并提供返回个人中心。真实登录、鉴权与焦点恢复需在生产实现中验证。

## 通知预览与主题

已登录顶栏按搜索、通知、主题、头像排列；登录页隐藏铃铛与已登录头像。Bell + Icon Button 点击打开 shadcn/Radix Popover，最多预览最近三条标题、正文摘要与已读状态，标题最多两行，右下角「查看全部通知」与头像通知中心进入同一页面。预览和通知列表均响应真实通知事件刷新；列表搜索传递服务端查询条件，切换全部/未读后回到第一页，Tabs 必须关联实际内容面板。

即时提示复用 Sonner，置于页面底部，最多显示一条并提供「关闭提示」，避免遮挡顶栏和堆叠占据手机视口。实时消息读取 MQ 的 data 对象内标题与内容；持久通知继续从铃铛与通知中心查看。

预览宽 350px、内边距 16px、组间距 8px；通知行上下 12px，标题与元信息间隔 4px。标题 20px、通知 14px、元信息 12px，绑定既有 popover/foreground/muted-foreground；沿用菜单圆角与轻阴影，无装饰边框。桌面/平板对齐铃铛右边线，下偏移 8px；手机左右避让 20px，宽度不超过可用空间，过长时使用 ScrollArea。

再次点击铃铛、外部点击、Esc 均关闭并返回焦点，不改变当前页。点击单条通知时先保存该条已读状态，再关闭并导航；失败保留预览供重试。预览打开不等于全部已读，不显示虚构未读数量；空态「暂无通知」，加载沿用共享加载状态。只能显示本人有权接收的通知。原型的发布通知进入我的内容、回复进入讨论、知识库更新进入知识阅读示例；生产根据真实目标 ID 导航。打开内容时保留通知列表的筛选、页码；目标失效或无权限时明确反馈并提供返回通知入口。

通知更多菜单提供删除，复用 AlertDialog 说明不可恢复；提交中防止重复操作，失败保留确认层与错误原因。删除末页最后一条记录后回到有效页，全部已读后未读列表显示真实空态。浏览器通知偏好只控制即时提示，不停止站内通知持久化或列表实时刷新。

头像、搜索和全站菜单同样遵守关闭与焦点规则。头像条目选择后关闭，角色保持；普通用户不渲染管理项，实际鉴权在服务端。主题使用 DropdownMenuRadioGroup：浅色、深色、跟随系统，选中项显示 Check；切换留在当前页，设置页使用同一偏好。原型系统主题按浅色演示，生产读取系统设置。原型角色/主题变量不代替真实会话或权限。

## 学习目录与阅读

当前目录覆盖 8 种算法，分类为全部/基础比较/进阶比较/非比较，数量 8/3/4/1；19 种是产品规划，不能把未设计内容当成已交付。搜索复用顶部 Command。

Card 内容为算法名、一句核心操作、平均复杂度与稳定性，Footer 仅保留右对齐「学习原理」。标题 18px、正文 16px、操作 14px、辅助 12px；内边距 16px、内部间隔 8px、列间距 16px、行间距 24px。桌面三列 416px、平板两列 344px、手机一列 350px。桌面/平板示例高 192px，手机与长文自然增高；不新增装饰编号或配色。

八种算法各有三端知识详情，内容按核心思路、步骤、具体变化、最好/平均/最坏复杂度、空间、稳定性、场景组织。桌面 864px 正文 + 48px 间距 + 368px 章节导航；手机/平板目录在正文前。每个卡片进入对应算法与尺寸，不错误跳到插入排序。Figma 中插入排序连接演练示例；代码中八种现有算法共用可视化工作台。返回目录保留筛选上下文，运行验证见 HANDOVER。

插入排序 O(n) 明确为最好情况；希尔复杂度取决于增量序列，基数排序注明位数 d 与基数 b。学习目录和阅读保持中性色。

## 社区、个人主页与 Data Table

社区参考连续信息流、作者关系和讨论结构，保持 AlgoFlow 顶部布局。桌面内容流 864px + 间距 64px + 话题栏 352px，公开主页为居中 864px；平板/手机单列。头像与正文、动态内部间距 12px，内容块间距 24px；帖子标题桌面 20px、手机 18px，正文 16px。私人进度、草稿与会话不自动公开。

| 页面 | 内容与组件 | 交互约定 |
| --- | --- | --- |
| 学习社区 | Tabs：精选/关注/待解答；Avatar、Textarea、Button 发布区；帖子流与话题 | 帖子可关联代码与算法演练快照；返回保留列表位置 |
| 讨论详情 | 原帖、算法快照、回复作者与上下文、回复输入 | 回复明确目标；失败保留输入；分页加载回复时保留阅读位置 |
| 公开个人主页 | 头像、名称、账号、简介、关注关系；动态/回复/学习笔记 | 展示公开内容；关注按钮需要已关注、提交中、失败回退状态 |
| 我的学习 | 学习记录、进度、最近学习时间、继续演练 | 使用 Data Table；私人学习进度不自动公开 |
| 我的内容 | 标题、类型、审核状态、更新时间、阅读量 | 使用 Data Table；编辑、预览、发布检查按记录状态可用 |
| 我的收藏 | 标题、作者、类型、收藏时间、来源 | 使用 Data Table；取消收藏反馈可恢复，不能影响原帖 |

帖子操作统一 Lucide：MessageCircle 回复、Heart 赞同、Repeat2 引用分享、Bookmark 收藏、Share2 分享、MoreHorizontal 更多。带数量的操作必须有「回复，4 条」等完整可访问名称；图标的填充/选中状态须同时传达操作状态。发布区 Code2 与 Paperclip 分别对应代码和关联演练。

社区流保留「加载更多」，后台与个人数据列表使用显式页码分页。公开个人主页使用内容流，不将阅读场景强行转成表格。未登录的发布、回复、关注和收藏应引导登录并保留草稿；权限校验在服务端执行。

### Data Table 组件契约

Data Table 按 [shadcn 官方指南](https://ui.shadcn.com/docs/components/radix/data-table) 组合 **Table + TanStack Table**，搭配 Input、Select、Checkbox、DropdownMenu、Pagination、Button、Skeleton、Alert 和 Empty。Data Table 是组合指南，不是可直接 `add data-table` 的独立 registry 组件；不得另写表格、选择框、分页器或菜单基础交互。

Figma 是可编辑设计映射，不代表官方 Figma Kit。代码中已补齐 Table、Checkbox、Select 与 TanStack Table v8；Radix base 和 default 风格保持不变，共享主题样式原位调整。

桌面结构为：工具栏 → TableHeader → TableBody → 选择反馈/批量操作 → Pagination。表头 48px、数据行 56px；复选标记 16px，置于至少 40px 的命中区域；操作列采用统一更多菜单。表格无外围框和纵向网格，选中行使用 muted 背景。排序列显示 ArrowUpDown 或当前方向；表头使用正确 `aria-sort`。

| 数据集 | 主要字段 | 行操作 |
| --- | --- | --- |
| 学习记录 | 算法、进度、最近学习、练习次数、状态 | 继续演练、查看笔记 |
| 我的内容 | 标题、类型、状态、更新时间、阅读 | 预览、编辑、发布检查 |
| 收藏 | 标题、作者、类型、收藏时间、来源 | 打开内容、取消收藏 |
| 知识库 | 名称、版本、索引状态、切片数、更新时间 | 原文、切片、索引任务、按修订号重试 |
| 社区审核 | 内容、作者、类型、原因、提交时间 | 查看原文与举报上下文，再执行审核 |
| 用户管理 | 用户、角色、状态、最近活跃、加入时间 | 角色、会话与访问限制分别确认 |
| 审计 | 时间、操作者、动作、对象、结果 | 查看请求 ID、变更详情与关联任务 |
| 索引任务 | 任务、文档、阶段、状态、更新时间 | 查看失败原因；按当前修订号重试 |

运营概览的有限待办、评测的有限来源结果复用表格结构；单任务的阶段详情保留顺序信息，不给有限步骤制造额外分页。

### 分页、筛选和选择

1. 分页显示当前记录范围、总数、每页条数、当前页和上一页/下一页。当前页使用 `aria-current="page"`。首尾箭头禁用且不可触发；单页两端均禁用。
2. 知识库 Figma 示例为 19 项、每页 5 项：第 1 页 1–5，第 2 页 6–10，第 3 页 11–15，末页 16–19；四页数据不同，桌面页码与前后页已连接。示例数字不是生产数据。
3. 每页 5/10/20 是设计选项。更改搜索、筛选、排序或每页条数时回到第 1 页；路由保留 query、filter、sort、page、pageSize，返回详情后恢复上下文。请求以服务端返回的 total、rows 为准，不从当前页长度推断总量。
4. 按页面声明的时间字段降序（内容默认发布时间，文档可选择更新时间），等值项用唯一 ID 排序，防止跨页重复或遗漏。翻页等待期间不将旧页伪装为新页；避免并发请求乱序覆盖。数据减少导致页码超出范围时回退到最后有效页。
5. 选择仅作用于本页。表头 Checkbox 支持未选、部分选中、全选；显示「已选 N 项（本页）」。翻页、改筛选或排序时清空选择。批量操作注明对象数量与影响，不暗含跨页全选。
6. 总数未知的首次加载与失败状态显示「总数暂不可用」，不伪装成 0，不显示确认的页码，禁用分页操作。空结果显示 0 项和清除筛选入口。刷新失败保留已有数据时必须标明数据未刷新。
7. 手机列表使用同一数据模型和分页状态，将行呈现为带字段标签的条目；保留名称、状态、时间、详情和分页。列显示入口进入 Sheet/DropdownMenu；密集数据确需宽表时，仅表格局部滚动，页面不得横向溢出。

## 个人工作区与运营管理

| 分区 | 内容与动作 | 设计规则 |
| --- | --- | --- |
| 概览 | 继续快速排序、待处理草稿/回复、最近学习记录 | 一个继续学习主动作，去除大菜单和装饰统计 |
| 学习记录 | 算法、学习状态、数组长度、演练进度、最近学习 | Data Table 与行操作，返回演练保留上下文 |
| 我的内容 | 标题、类型、状态、评论、更新时间 | 发布/编辑/草稿入口，手机编辑器提供保存草稿与发布检查 |
| 收藏 | 标题、作者、类型、主题、收藏时间 | 保留取消收藏与查看来源的操作契约 |
| 通知 | 回复、审核结果和知识库更新 | 全部标为已读、进入相关对象、必要分页 |
| 设置 | 个人资料、学习偏好、通知设置、账户安全 | 共用四类表单结构；账户设置正文提供其他设置入口，不使用跨页 Tabs 或分区菜单 |

桌面设置使用 320px 说明列 + 48px 间距 + 640px 表单列，手机单列。表单保留外部标签、只读字段与保存动作；Textarea 填满父级宽度并自动换行。账户安全当前展示具名只读邮箱与登录方式，使用邮箱验证码，不展示未实现的密码或会话管理按钮。活动会话与退出其他会话保留为后续能力；退出登录和管理入口统一放入头像下拉菜单。管理员入口必须按服务端权限控制，不能把括号提示当鉴权。角色变化撤销旧会话，过期时清除本地身份并提示重新登录，保留当前 URL。

公开个人主页继续展示资料与动态；私有草稿、会话、偏好不出现在公开页面。头像打开账户菜单，其中个人中心进入个人空间；Logo 返回首页；从私有记录进入公开内容仍需检查权限。

### 管理区域与数据列表

管理首页按「运营管理标题 → 需要处理 → 管理工作」组织。六个模块入口为知识库、召回评测、社区审核、用户与权限、索引任务和审计日志，置于正文；不在顶栏下重复设置栏目菜单，不堆叠大号统计。各管理内页保留左对齐「返回运营管理」，与现有标题、工具栏、表格和分页共同构成内容区。

模块入口复用 Card 语义结构与 Lucide ArrowRight；标题 14px、说明 12px，内边距 16px，文字与图标间距 12px，卡片间距 16px。使用 muted、foreground 和 muted-foreground，圆角 12px、无边框无阴影。桌面三列、平板两列、手机单列，文字宽度 Fill、长文自动增高，箭头保持 44px 命中区域。生产每张卡只对应一个语义链接，整卡与箭头共享目标，不制造嵌套链接或重复 Tab 停靠点。

个人概览同样在正文提供我的内容、收藏与账户设置入口；学习记录保留「全部学习记录」，通知使用铃铛和头像菜单。账户设置保留个人资料表单，并在正文提供学习偏好、通知设置、账户安全入口；这些子页返回账户设置。页面筛选 Tabs、表格操作菜单和弹窗保留，禁止把跨页面二次导航包装为筛选。

单层顶栏后的 Scroll viewport 高度为视口减 64px，位置统一从 y=64 开始；手机长内容自然纵向滚动，不裁掉底部模块。现有角色条件、头像菜单、通知预览、主题切换和危险操作确认保持同一契约。

| 模块 | 核心内容 | 详情与恢复 |
| --- | --- | --- |
| 知识库 | 文档、版本、索引状态、切片数、更新时间 | 导入、切片编辑、索引任务 |
| 召回评测 | 问题、知识版本、Top K、BM25/向量召回 | 来源与分数语义，避免跨检索器直接比较 |
| 社区审核 | 作者、关联算法、审核状态、提交时间 | 原文、处理原因、通过或退回确认 |
| 用户 | 角色、状态、最近活动、加入时间 | 权限与会话操作分别确认 |
| 索引任务 | 任务与版本、阶段、状态、更新时间 | 错误原因、刷新、按当前修订号重试 |
| 审计 | 操作者、对象、结果、时间、请求 ID | 详情可追溯，不展示凭证 |

桌面列表继续按 本规范 组合 shadcn Table + TanStack Table、Checkbox、Select、DropdownMenu 和 Pagination。手机记录使用共享 Mobile record 组合，正文带字段标签，44px 行操作按钮，不通过缩小字号塞入宽表。手机列表与桌面使用同一批示例记录；筛选和分页需在真实接口接入时保持同一查询契约。

知识库示例总数 19，桌面、平板、手机统一四页，范围依次为 1–5、6–10、11–15、16–19；前后页连接完整，首页上一页和末页下一页禁用。切换分页从目标页顶部阅读新记录，不沿用旧页底部位置。个人/管理列表示例为 5 条单页，通知为 3 条单页，分页边界按钮禁用。超过视口的分页在正文底部滚动可达。运营概览示例为待处理内容 3、失败索引任务 1，均为设计数据，不能作为实际业务统计。

### 执行、代码与操作位置

- 左 Card：数据摘要 → 暂存 key / 数据设置 → 数组柱体、数值、索引 → 当前步骤解释 → 步数与速度 → Slider → 上一步、播放、下一步、重置 → 比较 / 移动计数。算法名保留在页面标题，不在摘要重复。
- 右 Card：语言与步骤同步说明 → 完整实现代码、当前行高亮 → 当前变量 → 步骤分析 → 时间、空间与稳定性 → Footer 右对齐“解释当前步骤”入口；不再重复展示关联步骤的提示文案。
- 播放是主要动作。上一步、下一步在其两侧，重置位于同组右端；数据设置与速度不挤进播放按钮组。
- 图标按钮命中区域为 44×44，必须提供 Tooltip 和中文 aria-label；Tooltip 不能替代可访问名称。
- AI 导师按现有响应式路由打开。实施时提问绑定当前算法、数组、步骤和代码行的快照，返回保留执行状态。

栏目与设置图标、按钮及按钮图标、Slider 保持黑白主题，蓝色仅用于 key、当前柱体、执行变量与代码高亮；色值见主规范。浅底 Card 内 Slider 的未完成轨道使用 border token，已完成轨道和滑块使用 primary，保持可辨识。

设计示例采用数组 `[16,28,42,63,35,81,54,72]`：

- 第 4 步：i=4，j=3，key=35；比较 63 > 35，累计比较 4 次、移动 0 次。
- 第 5 步：执行 `a[j + 1] = a[j]`，数组中暂时出现两个 63；key 35 仍在独立变量中，移动计数变为 1。不能将原位置错误画成已经清空，也不能丢失 key。
- 生产步数须来自统一事件序列，代码行、变量、柱体、进度和计数消费同一快照；不能各自推算。
- 初始状态上一步禁用；播放切换为暂停；结束时下一步禁用并可重新播放；重置恢复第 0 步；单步和拖动先暂停。
- 修改数组先校验，失败保留输入与当前演练；成功应用后才重置。取消返回原上下文，不清空进度。数据设置使用 DialogTrigger 打开，关闭或按 Esc 后焦点返回触发按钮；导师弹窗遵守同一规则。
- 减少动态效果时跳过连续移动动画，仍提供逐步变化。键盘与焦点行为由 Radix 承担，生产需实测。
- 长代码在代码区滚动，不使整页横向溢出；错误、加载和空数据仍遵循全站规范。

### 动效与可访问性

GSAP 以 60 FPS 为目标，按实际设备和数据规模验证，不将目标当成测量结果。换位使用 power2.out；状态变换 duration 0.15s / power1.inOut。速率 ≥2x 简化辅助轨迹，4x 仍以可理解、可控制为先；prefers-reduced-motion 下保留单步与关键状态，跳过连续位移动画。完成时给出稳定状态和重练入口，不闪烁或自动庆祝。

WCAG 2.1 AA 是实施目标；键盘、可见焦点、读屏、缩放、触控与 reduced motion 需真实浏览器验证。所有交互复用 shadcn/Radix，数组 SVG/Canvas 仅是业务图形。失败保留输入，提交中显示 Spinner + disabled + 原标签。

### 响应式与组件实现约束

- 桌面正文操作不小于既有 40px；手机与平板点击高度至少 44px。图标视觉尺寸与命中区域分开，不能通过缩小图标按钮适配。
- 同组操作总宽度可容纳时并排靠右；不足时改为纵向、按钮填满可用宽度，主操作最后。真实浏览器的字体放大和文案变化也要触发换行。
- 单个卡片入口按内容宽度靠右；长表单的操作应与字段保持邻近，不置于页面遥远角落，也不增加常驻浮动按钮。
- 生产使用 CardFooter、FieldGroup/Field、DialogFooter、AlertDialogFooter、Pagination 等既有 shadcn/Radix 结构，用布局属性表达对齐，不能重新实现基础交互。
- Overlay 菜单继续遵循 本规范账户菜单章节：菜单文字左对齐、选中/状态标识在末端，不能把所有菜单项当作页底提交按钮右对齐。

## RAG 与真实数据边界

### 知识库元信息与模块返回

- 文档列表正文提供「管理知识库」，进入 `/admin/knowledge/bases`；沿用 DataTable、单层顶栏与右侧页头操作，不增加分区菜单。名称、说明和文档数来自真实接口，分页与搜索进入 URL。
- 创建和编辑复用 Dialog + Field；重名或请求失败保留输入，只有服务端成功后关闭。删除复用 AlertDialog，成功后刷新；有历史文档且索引无法清理时显示真实失败并保留知识库，不假报删除完成。
- 从知识库行进入文档、导入或召回评测时携带知识库 ID 与来源列表上下文，返回保留页码和查询。选择器首批之外的知识库通过管理列表查找，进入后按 ID 读取预选项，不能默默退回其他库。
- 个人内容从列表进入编辑，取消返回和提交成功均保留原页码与搜索。内容访问或编辑失败时也保留所属列表的返回入口。待审核正文只允许作者或管理员读取；公开列表与收藏不能绕过审核和删除状态。前端展示不代替接口鉴权。

### 切片草稿、冲突与索引

- 知识库和索引任务进入同一文档详情，返回保留来源列表的筛选和页码。切片沿用 DataTable；手机显示字段名、草稿状态与分页，不增加二次导航。
- 管理员在 Dialog 中编辑章节标题、路径和正文，正文最多 20,000 字符。保存按钮在操作区末端，提交中禁用重复操作。取消未保存内容时确认放弃；会话过期时以账号、文档和切片隔离的 sessionStorage 备份恢复本标签页编辑，保存和明确放弃后清除。
- 保存仅生成 DRAFT，检索仍使用已发布内容。文档 revision 是并发修订号，与课程 version 分开；草稿与重试均递增修订号，成功发布后更新 publishedRevision。
- 服务端返回 40900 时保留全部输入，不自动重试或强制覆盖。提供「加载最新版本」、只读比较、「采用最新内容」或「保留我的编辑并保存」；后者仍携带最新修订号再次校验。已重新发布或删除的切片不自动映射到新切片，提供复制编辑的退出方式。
- DRAFT 提供「建立索引」，FAILED / TIMEOUT 提供「重试索引」；PENDING / PROCESSING 不重复提交且暂停编辑。受理后只显示等待处理，自动刷新状态；仅 COMPLETED 表示新索引发布成功。
- 失败展示实际原因，保留草稿及当前检索版本。任务使用文档修订号领取和发布，重复、过期任务不能覆盖新状态。消息暂未送达时保留持久化排队状态，处理中超时转为 TIMEOUT 后可手动重试。


提问时固定算法、数组、步骤与代码行快照。回答保留流式、中断、断线恢复和来源标题/章节/版本；无可靠召回须明确告知，不伪造引用或相似度。未配置模型时返回明确失败事件，恢复原问题到输入框，允许修改后重试。索引区分已上传、已解析、向量化中、失败和已发布，结果不明先查询，再按任务与版本恢复。

设计中的用户名、计数、回答与列表数据仅为示例；所有真实数据、持久化、鉴权和业务回执由生产接口验证。交互组件来源、缺失 registry 与代码映射限制见主规范和 DES-06；不得手写平行基础组件。
