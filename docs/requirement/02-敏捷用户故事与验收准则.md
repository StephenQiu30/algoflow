## 故事 101: 算法单步与多速演示控制

* **故事 ID 与标题**：`US-101 算法单步与多速演示控制`
* **描述**：作为算法初学者，我希望在演练页面对算法执行播放、暂停、单步前进、单步后退并无级调速，以便于在复杂的递归或分区步骤中暂停思考并回溯数据流转。
* **来源与设计**：链接 [REQ-01 §3.1](01-产品总览与系统需求规格说明.md#fr-01-核心排序算法动态演练工作台-已确认) 与 [设计01 §7.3](../design/01-平台顶层微服务架构设计.md)、[设计02 §7](../design/02-Apple极简视觉与高帧率动效设计.md)。
* **讨论**：
  - *前置条件*：已选择任一排序算法并生成初始数组；
  - *业务意图*：推衍过程完全由学习者自主掌控，杜绝不可控的盲目快放；
  - *权限要求*：匿名全量开放；
  - *边界*：当前步数为 0 时禁止后退，到达终点时自动完成并高亮。
* **确认条件 (AC)**：
  - [x] **AC-1 正常结果**：点击播放以当前设定速率（如 1.0x）平滑播放；点击暂停在 50ms 内冻结画面与计时器；
  - [x] **AC-2 单步步进**：点击“单步前进”，仅推进一个微步骤，累计比较/交换次数相应累加，伪代码行同步跳动；
  - [x] **AC-3 单步回退**：点击“单步后退”，数组完全恢复到上一步快照，指标精确递减；
  - [x] **AC-4 速率调节**：滑块在 0.25x ~ 4.0x 范围内拖拽实时生效，无需重新开始演练；
  - [x] **AC-5 可访问性 (a11y)**：支持键盘快捷键（Space 播放/暂停，ArrowRight 下一步，ArrowLeft 上一步）。
* **追踪**：关联测试用例 `TC-SORT-001`、`frontend/tests/core.test.cjs`；实施状态见 BACKLOG `TSK-106`。

## 故事 102: 多形态与自定义测试数据集输入

* **故事 ID 与标题**：`US-102 多形态与自定义测试数据集输入`
* **描述**：作为进阶学习者，我希望选择极端数据形态（近乎有序、完全逆序、大量重复）或手动输入指定数组，以便于考查算法在极端情况下的时间复杂度退化表现。
* **来源与设计**：链接 [REQ-01 §3.1](01-产品总览与系统需求规格说明.md#fr-01-核心排序算法动态演练工作台-已确认) 与 [设计02](../design/02-Apple极简视觉与高帧率动效设计.md)。
* **讨论**：
  - *前置条件*：处于算法工作台；
  - *业务意图*：验证快速排序退化到 $O(n^2)$ 或计数排序处理负数/极端范围时的表现；
  - *边界*：自定义数组限制 3~30 项整数，超出或非法格式必须前端拦截。
* **确认条件 (AC)**：
  - [x] **AC-1 正常结果**：点击“近乎有序”，生成仅 1~2 对逆序元素的数组；点击“完全逆序”，生成单调递减数组；
  - [x] **AC-2 自定义合法输入**：输入 `12, 45, 2, 8, 33` 点击应用，工作台即刻载入该数据并重置指标；
  - [x] **AC-3 输入边界与例外**：输入含字母、空值或超过 30 项时，输入框下方出现友好提示红字，禁止载入；
  - [x] **AC-4 一致性**：自定义数据载入后，重新随机重置时仍能保留该输入项作为历史记录。
* **追踪**：关联测试用例 `TC-SORT-002`；实施状态见 BACKLOG `TSK-106`。

## 故事 201: 演练工作台当前步骤快照感知答疑

* **故事 ID 与标题**：`US-201 演练工作台当前步骤快照感知答疑`
* **描述**：作为遇到卡点的学习者，我希望向 AI 导师提问时系统自动挂载当前演练步骤的指针与数组快照，以便于无需复制粘贴即可获得针对性的即时解惑。
* **来源与设计**：链接 [REQ-01 §3.2](01-产品总览与系统需求规格说明.md#fr-02-领域感知-rag-增强型-ai-导师-已确认) 与 [设计04 §7](../design/04-RAG算法导师与知识检索设计.md)。
* **讨论**：
  - *前置条件*：演练工作台处于暂停或单步状态；
  - *业务意图*：降低提问门槛，AI 针对具体指针（如快排 low 与 high）进行启发式引导；
  - *边界*：网络断开时优雅重连，生成过程中允许主动取消（Abort）。
* **确认条件 (AC)**：
  - [x] **AC-1 上下文捕获**：打开提问抽屉，顶部胶囊清晰指示当前算法名称、当前第 N 步与当前高亮代码；
  - [x] **AC-2 流式输出 (SSE)**：点击发送后，首字输出时间 TTFB ≤ 1200ms，以打字机动效呈现 Markdown 与 LaTeX；
  - [x] **AC-3 权威溯源**：回答末尾展示 1~3 个官方知识库切片引用卡片，点击可打开原文段落预览；
  - [x] **AC-4 中断处理**：点击“停止生成”，前端立即中断 SSE 连接，后端释放大模型推理线程。
* **追踪**：关联测试用例 `TC-RAG-001`；实施状态见 BACKLOG `TSK-201`。

## 故事 401: 知识库 Markdown 自动化切片与向量化

* **故事 ID 与标题**：`US-401 知识库 Markdown 自动化切片与向量化`
* **描述**：作为平台教研管理员，我希望在管理后台上传算法教研文档时系统自动按标题语法树切片并同步至向量索引，以便于教研内容能实时被 RAG 导师精准检索。
* **来源与设计**：链接 [REQ-01 §3.6](01-产品总览与系统需求规格说明.md#fr-06-统一运营与切片管理后台-已确认) 与 [设计04 §7.2](../design/04-RAG算法导师与知识检索设计.md)。
* **讨论**：
  - *前置条件*：管理员身份登录，路由处于 `/admin/knowledge`；
  - *业务意图*：教研资料与 RAG 向量库实时联动，免除手动编写 SQL 插入向量；
  - *权限要求*：必须拥有 `UserRoleEnum.ADMIN` 角色。
* **确认条件 (AC)**：
  - [x] **AC-1 语法树分块**：上传包含 H1/H2/H3 标题的 Markdown 后，系统自动按 400~800 Token 窗口与 100 Token 重叠切片；
  - [x] **AC-2 向量化入库**：切片自动调用通义千问 Embedding 模型生成 1536 维稠密向量并存入 Elasticsearch；
  - [x] **AC-3 切片微调与编辑**：后台列表支持管理员手动修改切片文本或一键触发全量重新向量化。
* **追踪**：关联测试用例 `TC-ADMIN-001`；实施状态见 BACKLOG `TSK-303`。
