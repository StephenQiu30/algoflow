## 1. 业务背景与使命

数据结构与算法是计算机科学的核心基石。传统教学中，学生通常面临“静态伪代码抽象”、“动态指针与数组交换过程缺乏直观具象化”、“学习遇到阻碍时无人指导”的三大困境。

**衍序 · AlgoFlow 的核心使命**：
以**“推衍秩序 · 步进数据心流”**为指引，融合**高帧率算法可视化演练**、**领域感知 RAG 大模型导师**与**Apple 极简沉浸交互**，打造从“感性认知”到“理性推导”，再到“工程实践”的一体化交互教学平台。

## 3. 功能性需求规格 (Functional Requirements)

### FR-01: 核心排序算法动态演练工作台 [已确认]
* **FR-01.1 全量 19 种排序算法**：支持冒泡、选择、插入、希尔、快速、归并、堆、计数、桶、基数排序等基础与衍生算法。
* **FR-01.2 状态机控制**：提供播放/暂停、单步前进（Step Next）、单步后退（Step Prev）、调速滑块（0.25x ~ 4.0x）、重置。
* **FR-01.3 多形态数据集**：支持随机分布、近乎有序、完全逆序、大量重复及用户自定义合法数组输入（3~30 项）。
* **FR-01.4 指针与动态高亮**：精准区分比较中（琥珀黄）、交换中（红）、基准值 Pivot（紫）、已排序（绿）。
* **FR-01.5 性能指标实时演算**：动态累加显示比较次数、交换次数、当前步骤及时间复杂度对标。

### FR-02: 领域感知 RAG 增强型 AI 导师 [已确认]
* **FR-02.1 步骤快照自动挂载**：提问时自动挂载当前算法类型、步骤下标、数组快照与高亮伪代码行号。
* **FR-02.2 权威知识库切片检索 (RAG)**：基于 19 篇官方排序教研专章向量化切片，混合检索召回 Top-3 切片，幻觉率 < 2%。
* **FR-02.3 流式打字机答疑 (SSE)**：采用 Server-Sent Events 流式生成，首字 TTFB < 1200ms，支持 LaTeX 与代码块排版。
* **FR-02.4 答案引用溯源**：生成结果末尾附带知识库章节溯源卡片，支持用户一键定位深入阅读。

### FR-03: 算法知识库与学习路径 [已确认]
* **FR-03.1 19 篇官方教研文档**：涵盖原理、时空几何推导、伪代码、多语言实现与工业实践（TimSort 等）。
* **FR-03.2 学习路径导航**：提供新手进阶图谱与综合对比矩阵。
* **FR-03.3 全局混合搜索**：基于 Elasticsearch 的全站知识多路检索。

### FR-04: 社区交流与题解互动 [已确认]
* **FR-04.1 图文题解发布**：在线 Markdown 编辑器、实时双向预览与草稿暂存。
* **FR-04.2 点赞与评论互动**：支持文章轻量点赞、层级评论。

### FR-05: 用户认证与个人中心 [已确认]
* **FR-05.1 多方式注册登录**：账号密码、邮箱验证码与 Sa-Token JWT 分布式会话维系。
* **FR-05.2 学习足迹与成长勋章**：可视化展示已掌握算法数量与成就徽章。

### FR-06: 统一运营与切片管理后台 [已确认]
* **FR-06.1 统一内嵌架构**：严格统一置于 `frontend/src/app/admin/`，严禁独立工程。
* **FR-06.2 知识库切片管理**：基于 Flexmark AST 的分块微调、向量同步与召回评测实验室。
* **FR-06.3 安全审计**：API 访问日志与异常告警追踪。

## 4. 非功能性需求规格 (Non-Functional Requirements)

* **NFR-01 帧率与动效流畅度**：GSAP 动画硬件加速渲染，主流设备稳定保证 **60 FPS**（掉帧率 < 1%）。
* **NFR-02 交互延迟 (INP)**：演练控制器（步进/暂停等）操作响应延迟 **≤ 100ms**。
* **NFR-03 首屏加载 (LCP)**：前台页面最大内容渲染时间 **LCP ≤ 1.5s**。
* **NFR-04 视觉与无障碍 (a11y)**：严格遵循 Apple 极简设计规范（主色 `#0066cc`），文本与图表对比度满足 **WCAG 2.1 AA** 标准（对比度 ≥ 4.5:1）。
* **NFR-05 安全与合规**：网关统一鉴权过滤，输入严格执行 XSS 净化，持久层全面预编译防止 SQL 注入。

---

## 5. 架构与工程约束

1. **统一前端约束**：前台、演练工作台、AI 对话抽屉与 Admin 后台全量统一在 Next.js 15 App Router 工程；
2. **阿里巴巴 Java 规范**：微服务代码遵循《阿里巴巴 Java 开发手册》，接口响应强制返回 `Result<T>`；
3. **单一可信源**：教研知识以 `docs/algorithms/` 为权威来源。
