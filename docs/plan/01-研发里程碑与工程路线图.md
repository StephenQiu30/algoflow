## 1. 计划目标与交付范围

围绕“底座先行、核心聚焦、双向闭环、生态延展”推进，定义 AlgoFlow 的工程交付阶段，拆解各阶段的交付物清单、模块归属与前置依赖。

## 2. 前置依赖与环境要求

* **基础设施**：Docker Compose 环境（MySQL 8.0, Redis 7.0, Nacos, RabbitMQ, ES 9.3）；
* **构建要求**：Node.js 20+ (pnpm / npm), JDK 21 (Maven 3.9+)；
* **规范基线**：阿里巴巴 Java 规范校验与 Next.js 15 TypeScript 严格编译。

## 3. 里程碑阶段规划 (Milestones)

### 🚩 Milestone 1: 核心底座与算法演算引擎 (M1 - 基础夯实)
* **周期**：2026.09.01 ~ 2026.10.05 | **状态**：✅ **100% 达成 (Completed)**

  1. Monorepo 目录体系治理（`backend/`, `frontend/`, `docs/`）；

## 6. 风险识别与回滚预案

* **动效卡顿风险**：若 4.0x 极速推演出现微卡顿，激活降级策略跳过中间插值补间；
* **大模型网络抖动**：前端 SSE 封装断网 1 次重连机制，超时后弹出友好重试卡片。
