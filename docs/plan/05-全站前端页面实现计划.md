## 组件与文件边界

- 全局：SiteLayout / SiteHeader / Avatar DropdownMenu / Notification Popover / Theme DropdownMenu；一个顶栏，无第二行导航。
- 页面：PageShell 统一页边距、标题、返回和右侧操作；ModuleEntries 只保留业务模块入口。
- 列表：DataTable 组合 shadcn Table、TanStack Table v8、Checkbox、Select、DropdownMenu 与 Pagination；手机显示具名字段与同行操作。分页、查询、排序进入 URL，筛选重置页码；失败不伪造总数。
- 演练：保留 useSortingVisualizer 与纯事件引擎。业务柱体和代码用语义内容表达；按钮、输入、滑块、选择、弹层全部复用 shadcn/Radix。
- 新增基础组件通过 CLI 读取官方 registry；保留 default / Radix，baseColor 对齐 neutral，不切换 preset。Sheet 替换旧手写抽屉，使用官方 Radix Dialog Primitive。
- Geist 使用包内本地字体。Logo 使用当前 Figma A 矢量资产，不重新描绘。
- 鉴权复用现有账户状态与 Axios，不新建一套并行状态。前端隐藏入口不能代替网关鉴权。
- 清理已经无引用、已被新实现替代的旧控件与重复展示组件。设计预览保存在 assets/current 并原位覆盖。

## 配置与验证

默认请求 /api，Next.js rewrites 保留 /api 前缀转发到网关；ALGOFLOW_GATEWAY_URL 在构建前配置。跨域部署可显式设置 NEXT_PUBLIC_API_BASE_URL，必须包括网关要求的 /api 前缀。公开配置示例在 [frontend/.env.example](../../frontend/.env.example)。

本地检查：pnpm run typecheck、pnpm run lint、pnpm test、pnpm run build。浏览器覆盖 1440 / 768 / 390 / 320 宽度；验证菜单进入与关闭、返回、权限、分页边界、失败恢复、表单保留、排序事件与代码同步。

隔离夹具只在 frontend/tests/fixtures-api.cjs，明确标注测试数据，绑定 127.0.0.1:3212；仅通过显式测试启动参数接入，不被应用导入，不设为默认数据源。CI 冒烟脚本随当前标签和控件更新，CI 是否通过以实际运行结果为准。

## 后续真实联调与未覆盖能力

已复用本机现有 Nacos、MySQL、Redis、RabbitMQ、Elasticsearch 完成真实网关、个人资料/内容/收藏、管理权限/审核/审计、通知持久化与 WebSocket 的限定流程验收；具体范围见 HANDOVER。邮件投递/OAuth、COS 上传、模型回答与真实向量检索仍待供应商配置；受控验证码前置条件不代表邮件投递成功。

MessageScroller / Message / Bubble 在本次 @shadcn registry 检索中未提供；当前采用官方 ScrollArea、Dialog、Field、Textarea、Button 与语义文章组合，未伪造聊天组件。流式跟随、暂停跟随和中止属于业务逻辑。
